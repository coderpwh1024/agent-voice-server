# 语音图像生成与编辑

通过 `image_voice_operation` 为当前语音请求返回一个操作。调用时使用 Pydantic 工具参数契约，服务端校验图像归属、作品状态、输入参数、幂等和任务额度。

## 先确认目标媒介与本轮动作

1. 看用户本轮明确要求生成、修改或查询的作品类型。生成、编辑静态画面，以及查询本人图片的详情或按标题、画面关键词查找作品，属于图像操作。画面的题材、用途和引用素材不改变产物类型。
2. 「做一张视频封面图」「画一张作为视频首帧的图片」的产物是静态图像。提供图片并要求生成短片、动画或连续镜头时，图片是输入素材，产物属于视频。图像 Skill 收到这类请求时使用 `clarify`，不提交图像任务。
3. 「从视频里截一张图」「更换已有视频的封面」涉及读取或修改视频资源。图像工具只生成或编辑图片。收到这类请求时使用 `clarify`，不能用生成一张相似图来替代所需操作。
4. 明确请求「先做一张封面图，再做视频」时，本轮只处理已明确的第一项。用户同时要求两种产物、顺序未定，或者「做一下」「弄成动态的」缺少可判断的媒介时，用 `clarify`。不能自动提交两种任务。
5. 本轮明确切换媒介时以本轮要求为准。仅把本线程最近图片用于解析「这张图」等指代。编号本身、历史视频草稿、上轮建议、讨论或引用均不能作为本轮操作的授权。区分各动作的肯定和否定，例如「不要生成视频，给我画一张海报」中的正向请求是静态海报。

| 本轮话语 | 目标与图像工具决定 |
| --- | --- |
| 「给海边短片画一张封面图」 | 静态图像，提取用户给出的画面要求后用 `create` |
| 「把十二号图片的天空改成灰蓝色」 | 静态图像，使用 `edit` 和图片编号 12 |
| 「用这两张图片当首尾帧，生成五秒短片」 | 视频，图像工具使用 `clarify` |
| 「看看 12 号做好了吗」 | 媒介或作品不明确，使用 `clarify`，除非明确承接本线程刚确认的图片 |

## 生成 `create`

用户明确要求新建一张图像，并给出画面描述时，提取为 `prompt`。保留用户提出的主题、风格、构图、颜色、尺寸描述和内容限制。没有描述时用 `clarify`。

用户说「帮我生成一张图，蓝色湖面上有一艘橙色纸船」时，使用 `create`，`prompt` 为「蓝色湖面上有一艘橙色纸船」。

## 编辑 `edit`

从用户当前话语中提取要修改的内容，保留明确要求维持的细节。用户报出作品编号时填入 `image_id`。用户明确说「这张图」「上一张图」时，可省略 `image_id`，由后端解析本线程最近的本人作品。目标不明确时用 `clarify`。

用户说「把十二号图片的背景改成雾蓝色，保留人物」时，使用 `edit`，`image_id` 为 `12`，`prompt` 为「把背景改成雾蓝色，保留人物」。

同一轮多项可以一起完成的修改放在同一个 `prompt`。明确要求分步编辑时只提取第一步，等新版本保存后由用户发起下一轮。编辑生成独立作品，每条语音编辑链最多追加五代。

## 查询 `detail`

用户按编号查询作品详情、生成状态或是否保存成功时，使用 `detail`。输入作品编号时填入 `image_id`。明确指代本线程最近的唯一作品时可留空，由后端解析。多图结果之后，请用户说出具体编号。

用户说「查一下十二号图片好了吗」时，使用 `detail`，`image_id` 为 `12`。状态和七牛图像地址以工具执行结果为准。

## 查找 `search`

用户按标题或画面内容查找图片时，使用 `search`。从本轮原话提取连续的作品名或画面关键词填入 `query`。明确按标题查找时设 `search_field=title`，按画面内容查找时设 `search_field=content`，维度未明确时可留空。画面内容检索依据已保存的生成描述。搜索可能返回多张图片，数量和预览以工具执行结果为准。

「找标题叫远山的图片」使用 `query=远山`、`search_field=title`。「看看有没有画着蓝色小船的图片」使用 `query=蓝色小船`、`search_field=content`。查询条件不清楚时使用 `clarify`。

## 浏览近期图片 `recent`

「看看我的图片」或「看看我最近三天的图片」使用 `recent`。按编号、标题或画面关键词的有效查询未命中时，服务端自动查询最近 72 小时创建的本人图片任务。播报和展示以服务端实际返回的记录为准。

## 停止或补充 `clarify`

只讨论能力、引用他人话语、取消、先考虑、超出图像工具范围或缺少必要参数时，只返回 `action=clarify`。删除、重命名、上传新素材和浏览完整图集在图像工作室完成。工具执行后由运行时报告真实结果，等待下一轮由用户决定是否继续。
